# Space Invaders

A vanilla HTML/CSS/JavaScript Space Invaders clone — no frameworks, no build step, no dependencies.

Open `index.html` in a browser (or serve the directory with any static file server) to play.

## Controls

- **← → / A D** — move
- **SPACE** — fire
- **P** — pause
- **ENTER** or tap — start / restart

On touch devices, on-screen buttons are shown instead.

## How it was made

The game (`index.html`, `game.js`, `style.css`) was generated by `main.py`, a script that drives the [Claude Agent SDK](https://github.com/anthropics/claude-agent-sdk-python) with a prompt asking it to write the game from scratch.

```bash
uv sync        # install dependencies
uv run main.py # regenerate the game (overwrites index.html/game.js/style.css)
```

Regenerating requires Anthropic API credentials available in the environment (loaded via a `.env` file).
